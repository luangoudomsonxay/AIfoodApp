# AIfoodApp (ແຊບລາວ)

Mobile web app recommending Lao dishes with prices (in kip). Plain HTML, data saved in localStorage, AI food images via the OpenAI API.

- `index.html` – Lao-language version (Phetsarath OT font, falls back to Noto Sans Lao)
- `lao-food-app.html` – Thai-language version
- `lao-food-app-lo.html` – copy of the Lao version

## Use
Open the page, go to Settings (ຕັ້ງຄ່າ), enter your own OpenAI API key, then open a dish and tap the AI image button. The key and images stay in your browser only.

For the Phetsarath OT font, install it or place `Phetsarath_OT.ttf` next to `index.html`.
